Turn the requested content into purposeful, recognizably Duke work. Use the project's tools and conventions. Preserve supplied facts; identify demonstration content. This skill supplies design guidance, not trademark permission or a claim of institutional approval.

4. 5. Inspect the actual output at intended sizes, use the [review checklist](references/review.md), and correct defects. Distinguish visual inspection from source review. If rendering or interaction testing is unavailable, say exactly what remains unverified.
6. Deliver the artifact with a short account of design choices, checks performed, and remaining asset, approval, or access limitations. Continue independent work when an optional resource is missing; stop only the affected work when essential evidence or authorization is absent.

## Authority labels

References distinguish **Duke rule** (explicit requirement/prohibition), **Duke recommendation** (advice, suggested use or example), **Skill default** (reversible implementation choice), and **General accessibility practice** (not a distinct Duke visual-brand rule). Source-specific scope matters. Do not upgrade “should” to a mandatory policy or turn an example into the only permitted design.

**Skill default — action styling:** Do not add decorative arrows (such as ↗ or →) to links or action buttons. This includes text glyphs, icons and CSS-generated arrows. Use descriptive labels and clear styling. Functional previous/next controls or disclosure indicators remain appropriate when they explain behavior; an external-link arrow must not label a local calculation, render or download action. This is a developer-requested design preference, not a Duke brand rule.

Use official asset files for marks; never typeset or trace a substitute. This folder includes reference diagrams, not production logos or licensed photography. Restricted downloads require a legitimately supplied asset; no credentials or access-control workarounds. Existing institutional authorization in the user's context need not be requested again.
