# How this project was made

- `plan.md` is the plan, in the words of the student who wrote it, with their approval.
- `journal/` holds one entry per working session: what was asked for, the questions and answers, what changed, and what was checked.
- `backlog/` holds one file per feature or bug, with who reported it and how much it matters.
- `screenshots/` holds the desktop and phone views from the most recent check.
