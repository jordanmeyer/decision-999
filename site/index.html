From discovery to practice

Get started.

You’ll need Codex with plugin support. Register this marketplace, then choose and install a plugin.

01 Add the marketplace

Run this command in your terminal to make the collection available in Codex.

codex plugin marketplace add jordanmeyer/decision-999

02 Inspect, then install

Adding the marketplace does not install a plugin. Open the package instructions to review its contents, install it, and learn how to invoke the skill.
