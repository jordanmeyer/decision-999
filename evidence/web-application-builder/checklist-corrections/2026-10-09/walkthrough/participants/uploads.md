# Common Goods — participant task

[Open the app](https://jordanmeyer.github.io/bab-example-uploads/). Reload or reset it before starting.

Allow 12 minutes. Start from the default app supplied by the facilitator. Use only synthetic files. Think aloud; this reviews the app, not you. State predictions before changes or worked answers. You may use the app's guidance. Stop at the time limit and describe unfinished steps.

1. Describe which channel appears strongest before returns and whether that conclusion survives after returns. Explain what these results can and cannot say about profit.
2. Predict whether the overall channel story holds for every product and month. Use Trends & interactions to inspect Everyday tee × Email, then May. Explain the counts behind the rates and return to the full matrix.
3. Open the cohort-maturity example. Before loading its snapshots, predict what later returns will change. Compare both snapshots and use Joined rows to explain how the return events become one sales row.
4. Restore the sample and download both files. Save copies with distinctive filenames. In the returns copy, change one line ID to `MISSING`. Import the pair, explain the error and identify which dataset remains active. Correct the ID and import the corrected pair. Explain how you know which files are now being analyzed.
5. Choose a filter and export a summary. Identify its grouping, cohort basis and observation date. State one finding, one limitation of comparing cohorts of different ages, and how you will keep the work after closing the tab.
