# Common Goods: how this was built

Which sales are lost to returns? Follow a gross-sales lead erased by returns, then compare sales cohorts and product–channel combinations.

An instructor-run example with synthetic data and a recorded simulated planning conversation. The current app was revised against Browser App Builder 0.2.3 guidance, independently reviewed and checked at its live GitHub Pages URL. The preview captures that revised application.
