## Resolved conflicts and open limitations

- **Typography versus mark:** legacy Garamond phase-out applies to ordinary typesetting; S3 still requires unchanged official wordmark artwork. Never replace it with EB Garamond.
- **Historical specimen copy:** the paragraph calling Prussian Blue Duke's official color is sample text, not the current palette specification. S5 governs current values.
- **Sub-brand text versus diagrams:** use the specific approved asset/template for its variant; Canvas B's semibold/title case and two-line bold/caps are not interchangeable. Do not generalize example measurements or invent missing template details.
- **Print minimum versus screen:** S3's illustration explicitly limits the 3/8-inch minimum to print. No pixel minimum inferred.
- **Roboto Mono fallback:** S6 supplies a serif stack despite the monospace role. The skill's explicitly labeled monospace fallback preserves the function.
- **Font version drift:** S6's old specimens/weight inventories and Google UI directions are not evidence of every current provider version. Verify actual files/styles for the project.
- **Accessibility date/scope:** S11's later, more specific web guidance supplements S5; 2.1 is encouragement, not an invented 2.2 rule. Exact calculations resolve inconsistent grid rounding.
- **Shackleford PMS:** S5 prints “7527 U / 2527 C.” Preserved verbatim as data; confirmation is needed before a coated spot-color job, not for unrelated designs.
- **Optional inaccessible material:** no unseen photo treatments, video package specifications, downloadable template dimensions or unit policies are claimed. Public guidance supports general design work; task-specific dependencies remain explicit.
