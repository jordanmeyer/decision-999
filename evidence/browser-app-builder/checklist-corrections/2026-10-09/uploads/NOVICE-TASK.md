# Common Goods novice task — no answer key

Open the reviewed Common Goods build in its default state. Allow about 12 minutes. Use only the supplied synthetic files.

1. Describe which channel appears strongest before returns and whether that conclusion survives after returns. Explain what the result can and cannot tell you about profit.
2. Predict whether the aggregate channel story will hold for every product and month. Use Trends & interactions to inspect Everyday tee × Email, then May. Explain the counts behind the percentages and return to the full matrix.
3. Open the cohort-maturity example. Before loading the snapshots, predict what a later return will change. Load both snapshots, then use Joined rows to explain how the raw events become one sales row. Name a limitation of comparing early and mature cohorts.
4. Restore the sample. Download both files and inspect their headers. In copies, change one return's line ID to MISSING, import the pair, explain the error and determine which data is still active. Correct the ID, then enter returned units greater than the matching sold units and try again. Recover by importing a corrected pair. Explain how you know which filenames are currently being analyzed.
5. Choose a filter and export a summary. Identify its grouping, cohort basis and observation date from the file. State one finding and one thing the export cannot establish. Explain how you will keep the work after closing the tab.
