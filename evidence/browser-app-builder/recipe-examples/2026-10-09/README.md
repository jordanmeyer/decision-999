# Ten recipe examples — work in progress

Requested outcome: ten original applications, realistic simulated planning, independent persistent review/revision until pass, and per-app verified GitHub Pages publication with plugin gallery links. The machine-readable [status](status.json) is the current checklist. [Opening briefs](BRIEFS.md) are prompts, not claims of completed conversations or student outcomes.

Working app repositories: /private/tmp/bab-recipe-examples-2026-10-09/. Developers own separate folders; the coordinator answers planning questions, owns plugin changes and publication, and commissions independent reviewers. Source/evidence snapshots will be saved here before relying on temporary folders. Existing trial apps are not reused as implementations.

Only the Remotion video app has user authorization for its documented render-event telemetry; other applications retain the no-external-runtime/no-telemetry boundary. Exact specialist configurations, licenses and operational limits are being verified before approval.
