# Ship

Read [the conversation rules](../../references/conversation.md) and [the design rules](../../references/design.md). Ask: "Who is working with you today?" Run `course start <project>`. If the README already has a teammate's answers, skip to step 3 of Run.

## Ask

1. In one sentence, what value does this app deliver, and to whom?
2. What limitations would you tell a manager before they relied on it?
3. Who may reuse your work? Tell the student: "The default is the MIT licence: anyone may reuse the code if they keep your names on it."
4. What would need updating in a year?
5. What should a demo-day audience remember?

## Run

1. Finish the README with these answers, add the chosen licence as `LICENSE` naming the team, and put the value sentence in `app/site.json` as the tagline.
2. Read the plan, journal and backlog, and create `process/pitch-starter.pptx` with your PowerPoint ability: problem and user, cost today, a screenshot and the live link, how it works, the worked example, what changed after feedback, limitations and next steps, the team. Begin every slide's notes with "REWRITE:" and what the students must change.
3. End the session, adding `--mine` to the publish command so the student keeps an own copy.

## The student sees

"Your team's app is live at <address>, your own copy is at <address>, and the pitch starter is in the project's process folder. Rewrite every slide marked REWRITE."
