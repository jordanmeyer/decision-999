# Synthetic browser fixtures

These are maintainer-authored fixtures, not evidence of an independent agent building an app or a student completing the workflow. Serve this directory through any existing loopback preview and open each tests page. No installation or framework is needed.

Pricing models `(price − unit cost) × quantity − fixed cost`. With 20, 12, 100, 500 the answer is 300; 500/8 gives 62.5 continuous units, so 63 whole units cover costs. At 62 units profit is −4; at 63 it is 4. A nonpositive margin with positive fixed cost has no break-even quantity. Prices/costs/quantity are finite and nonnegative. No fixed cost means zero units is a break-even point. The UI restricts quantity to whole units.

Inventory assumes independent days, with stock reset to the supplied amount each day. Demand is uniformly drawn from integer 0 through maxDemand using an explicitly seeded illustrative generator. Remaining stock is max(0, stock − demand); unmet demand is max(0, demand − stock). The accounting identity is stock + unmet = demand + remaining. No calibration, distribution-quality claim, or statistical accuracy result is implied.

For defect detection, copy the pricing fixture to scratch, change the profit formula to add 1, and open its tests page. Known-answer and boundary cases must fail. Restore the formula and reload to confirm the correction. Do not modify this preserved fixture to record a failed run.
