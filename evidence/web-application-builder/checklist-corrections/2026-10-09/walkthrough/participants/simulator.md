# Seasonal Order Lab — participant task

[Open the app](https://jordanmeyer.github.io/bab-example-simulator/). Reload or reset it before starting.

Allow 8 minutes. Start from the default app supplied by the facilitator. Think aloud; this reviews the app, not you. State predictions before inputs change or worked answers open. You may use the app's guidance. Stop at the time limit and describe where you reached.

1. Explain the opening recommendation. How does it differ from the order with the highest expected contribution before the risk screen?
2. Predict the effect of increasing the maximum chance of loss from 3% to 20%. Change it, run and explain the result.
3. Leave selling price blank and attempt a run. Explain the feedback and which assumptions the retained result uses. Recover a valid scenario.
4. Inspect the recommended order's downside and one shared scenario. Explain why the compared quantities face the same demand and cost in that scenario.
5. Copy the completed assumptions. Name one reason this result alone cannot establish that a real launch should proceed.
