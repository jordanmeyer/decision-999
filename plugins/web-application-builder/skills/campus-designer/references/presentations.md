# Presentations

Use shared color, typography, mark and imagery rules. [Duke's Downloads & Print Resources](https://communications.duke.edu/communicator-resources/downloads-print-resources/) offers PowerPoint themes and backgrounds for other presentation tools; the linked ZIP requires sign-in. See [S13](sources.md). An unavailable template does not imply a new layout is forbidden.

**Skill defaults:** Start with an existing authorized project template when supplied. Otherwise choose a coherent heading/body pairing, unchanged Duke blue and sparse supporting accents. Build slide hierarchy around each slide's claim and evidence; vary title, image, chart and reading layouts as the content needs. Use a stable grid and consistent title placement without forcing identical slide bodies.

Design for the room or viewing context: enlarge text and simplify dense graphics until readable at intended display size. Put extra explanation in notes or additional slides rather than compressing type. Preserve source numbers, chart labels and qualifications. Do not invent a standard Duke slide aspect ratio, title size, logo corner or decorative treatment.

**General accessibility practice:** Provide unique descriptive slide titles, logical reading order, meaningful alternatives, non-color data encodings, sufficient contrast and captioned video. Check actual font availability and embedding rights before handoff. A fallback can change wrapping; recheck every slide after export.

Inspect a full-slide overview for consistency, then every rendered slide at intended size for clipping, crowded margins, small labels, image quality and contrast. If a handout is also requested, separately inspect that print output and apply the [print-specific logo measurements](marks.md). Do not assign inch-based print rules to an on-screen slide as a universal digital requirement.
