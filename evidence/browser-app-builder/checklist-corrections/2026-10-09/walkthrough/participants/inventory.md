# Inventory — participant task

[Open the app](https://jordanmeyer.github.io/bab-trial-inventory-2026-10-08/). Reload or reset it before starting.

Allow 9 minutes. Start from the default app supplied by the facilitator. Think aloud; this is a review of the app, not a test of you. State predictions before changing inputs or revealing worked answers. You may use the app's guidance. Stop at the time limit and describe where you reached.

1. Explain the default fill rate, unmet demand and ending stock. What does this single run tell you about the policy, and what does it leave uncertain?
2. Load the delayed-delivery example. Before inspecting days 2 and 3 or revealing the worked answer, predict whether another order is placed on day 2 and what happens on day 3. Use the ledger to explain the result, including stock already on order.
3. Keeping that example's other inputs unchanged, predict the effect of comparing reorder point 6 and order quantity 6. Run the comparison. Explain the tradeoff using service, average stock, ending stock and outstanding orders.
4. Leave lead time blank, attempt a run and recover a valid case. Explain which assumptions any displayed outcome belongs to.
5. Save the complete run JSON. Explain the difference between final on-hand stock and a delivery after the horizon. Name one missing consideration before choosing a policy for a real operation.
