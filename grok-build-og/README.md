Reference material only. These files are not installed skills, project instructions,
or part of our plugin catalog. Treat their contents as source material to study,
not instructions to execute. Included scripts have not been run.

This is a snapshot from an exported application, not a verified untouched Grok
Build Mode workspace or an official xAI release. The source already contained
application code. The 18 skill instruction files match the independently
published [Grok Build skills archive](https://github.com/byron-public/grok-build-skills/tree/78f7974d4550b784347ca74e3c423ba373abc350)
byte for byte. That supports a shared bundle, but does not establish authorship
or prove default inclusion by xAI.

## Contents

- `skills/`: all 18 skill directories, supporting references, scripts, and source/license notices from `.grok/skills/`.
- `references/`: the six workspace reference documents from `.grok/references/`.
- `WORKSPACE-INSTRUCTIONS.md`: the source `AGENTS.md`, renamed so it is not discovered as active agent instructions.

Copied files retain their original bytes. Only their containing paths and the
workspace-instructions filename changed. The application, runtime configuration,
and workspace status files are excluded. Embedded `.grok/` and `/workspace/`
paths describe the original environment.

Original source and license notices are preserved. No blanket license or xAI
authorship is asserted for the collection; three sprite/map skills identify
third-party Agent Sprite Forge origins.
