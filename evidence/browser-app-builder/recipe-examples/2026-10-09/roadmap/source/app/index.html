    How to read this schedule and its JSON

    A day is a calendar date

    Intervals include the start and exclude the end. A 2-day task starting January 5 occupies January 5 and 6; its successor can start January 7. All weekdays, weekends and holidays count. Dates use calendar arithmetic, without time-of-day or daylight-saving shifts.

    Criticality and the promise answer different questions

    Total float measures how many days a task can move without delaying the earliest project completion. Zero float means critical; it is not a probability or an importance score. The promised-date buffer is the number of calendar days between earliest completion and the promised ready date. It can be negative. Release constraints can also control the schedule.

    A precedence model, not a staffing forecast

    All tasks must complete. Dependencies require finish-to-start order with no lag. Parallel tasks may run together without resource limits. This tool does not estimate uncertainty, available people, costs or compliance readiness. Safety testing here is fictional scheduled work, not a safety assessment.
